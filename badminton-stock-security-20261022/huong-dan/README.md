# Hướng dẫn sử dụng bộ nộp

Xem [README chính](../README.md) để chuẩn bị `.work`, chạy đúng file pytest và runner. `chuan_bi.py` chỉ ghép bản sao mã C, Python, đặc tả, Excel, test và nguồn Java về cấu trúc gốc; không chạy fuzz, không cài compiler và không ghi đè file làm việc đã thay đổi.

Báo cáo mới nằm ở [bao-cao/Baocao.docx](../bao-cao/Baocao.docx). Hướng dẫn trình bày cá nhân của nhóm được giữ cục bộ, không cần để trong bộ nguồn cho giảng viên.

File `.work/` và kết quả mới trong đó được Git bỏ qua. Chỉ bắt đầu chạy sau khi đã kiểm tra Python, gcc/gcov và đúng file mục tiêu. Compiler, môi trường Python, EXE và DLL không được đóng gói.
